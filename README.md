Современный, красивый и интуитивно понятный веб-интерфейс для генерации видео и озвучки с использованием ведущих нейросетей (**Kling AI**, **Hailuo AI / MiniMax**, **Pika Labs 2.0**, **Luma Dream Machine** и др.). 

Проект разработан в нежном стиле **Soft Neo-Brutalism & Modern Pastel** и поддерживает комбинированный ввод: **Текст + Фото + Голос/Озвучка (LipSync)**.

---

## ✨ Основные Возможности

- 📝 **Text-to-Video & Image-to-Video:** Генерация ролика по текстовому описанию (промпту), по загруженной фотографии или по их комбинации.
- 🎙️ **Озвучка и LipSync (Синхронизация губ):**
  - Генерация голоса диктора через Text-to-Speech (TTS).
  - Запись собственного голоса с микрофона прямо из браузера (через Web Audio API).
- 🤖 **Мультимодельный выбор:** Поддержка нескольких популярнейших нейросетей с автоматическим подсчетом расходов и баланса.
- 💳 **Динамический учёт кредитов:** Автоматический перерасчет токенов/кредитов с учетом выбора модели и включения озвучки.
- 🎨 **Стилизация:** Быстрый выбор стилей (Реализм, 3D Мультфильм, Аниме, Экшн / Кино, Киберпанк).
- 🎥 **Настройки камеры и качества:** Выбор движения камеры (Zoom In, Pan, Tilt) и разрешения (720p, 1080p Full HD, 4K).
- 🔑 **Авторизация через Google (Simulated):** Готовая интеграция кнопки авторизации для получения ежедневных бонусов.

## 🚀 Быстрый запуск

Данный проект полностью автономный и написан на чистом **Single-File HTML/CSS/JS**. Для запуска не требуется установка Node.js или тяжелых веб-серверов.

### Способ 1: Прямой запуск
1. Скачайте файл `index.html`.
2. Двойным кликом откройте его в любом современном браузере (Chrome, Edge, Safari, Firefox).

### Способ 2: Клонирование репозитория
```bash
# Клонируйте репозиторий
git clone [https://github.com/your-username/kling-ai-video-studio.git](https://github.com/your-username/kling-ai-video-studio.git)

# Перейдите в папку проекта
cd kling-ai-video-studio

# Откройте index.html в браузере
open index.html # для macOS
# или
start index.html # для Windows
